# Contributing Guide

Thank you for contributing to AI Medical Record Extractor.

## How to Contribute

1. Create a new branch

Example:

git checkout -b feature-name


2. Make your changes.

3. Test your changes.

4. Commit your code.

Use meaningful commit messages:

Example:

feat: add medical record extraction


5. Push your branch.

6. Create a Merge Request.

## Code Rules

- Write clean code
- Add tests
- Update documentation
- Follow project structure

## Development Setup

Install dependencies:

pip install -r requirements.txt

Run tests:

pytest
